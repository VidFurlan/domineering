# Domineering Solver

Implementation of a solver for the game **Domineering** using a state-space search and different performance optimizations.

## Features

- game solver (generator/)
- web state graph visualizer (visualizer/)
- playable demo (playable_demo/)
- runner and benchmarking gui (runner/)

## Build
To build the solver use:
```bash
cd generator
mkdir build
cd build
cmake ..
make
./Generator --help
```
